# PRF2Bokeh 
A command line utility for generating interactive Bokeh plots from [FullProf](https://fullprofsuite.github.io/FullProf-Web/index.html) .prf files

## Usage:
When the script is invoked without arguments in a directory it will search for .prf files within that directory.
The script may also be invoked with the path to a .prf file as an argument.
The script searches the same directory for .sub files containing partials data for a Rietveld plot (.sub files for a refinement can be generated by setting Ipr = 2 in the .pcr), these may also be specified / overridden via the command line.
The script will generate and open a local webpage in the default web browser containing an interactive Rietveld plot using the [Bokeh] module(https://bokeh.org/). 
Switching between obs intensity  & log(obs) as well as 2theta/TOF & d-spacing is available, points may be added and exported as a .csv. 
The interactive webpage can also be saved as a .html, allowing for easy sharing / presenting.

## Limitations:
The plot does not automatically update as Winplotr does from the FP suite, however the same .prf may be re-read without restarting the script. 
Other features from Winplotr are also not available, such as the ability to call FP from the CLI / generated webpage.
The point list is exported as a .csv, this list would require reformatting for use with other FP programs such as Dicvol or K-search.

## Examples
Examples folder contains .html files of plots generated from examples available on the FullProf [documentation](https://fullprofsuite.github.io/FullProf-Web/documentation.html) page.
